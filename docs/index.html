Two-road traffic light system on the XNUCLEO-F103RB

An STM32F103RB controller for a two-road intersection with automatic, manual and timing-adjustment modes, live temperature and humidity on an I2C LCD, and every task run by an O(1) cooperative scheduler.

What the system does

Three operating modes share the same two signal heads, selected from an LCD menu with the push buttons. The two roads are never green at the same time, including during mode changes.

Automatic

Both roads cycle Red, Green and Amber in turn using the configured durations, driven by software timers.

Manual

The operator steps the intersection through its light states with push buttons.

Timing adjustment

Pick a light, raise or lower its duration, confirm. Invalid combinations are rejected and the LCD shows the value being edited.

Environment display

A DHT20 sensor is read over I2C at a fixed period and the temperature and humidity appear on the LCD.

How it is built

The firmware is built bottom-up, one layer at a time, and each layer is tested before the next one is added. Only the module layer touches the HAL.

1

Hardware

STM32F103RB, two light modules on D3–D6, four buttons on D7–D10, DHT20 and LCD on I2C1, TIM2 tick every 10 ms.

2

O(1) scheduler

Delta-sorted task list so SCH_Update only checks the head task. Supports periodic and one-shot tasks.

3

Supporting modules

Software timer, debounced buttons, traffic light driver, DHT20 and LCD drivers, each as a .h/.c pair.

4

State machines

fsm_automatic, fsm_manual, fsm_tuning and a mode switcher, running as scheduler tasks with no direct hardware access.
